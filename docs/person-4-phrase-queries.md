# Person 4 — Phrase Queries and Ranking

## Module
`src/phrase_queries.py` searches the positional index generated by
`src/positional_index.py`. It handles the required phrases:

- `patient care`
- `medical research`

## Exact phrase matching
The index maps each term to document IDs and 1-based token positions. For a
phrase with terms t1 ... tk, a document matches only if there is a position p
such that p occurs for t1, p+1 occurs for t2, ..., p+k-1 occurs for tk.
This enforces both adjacency and word order. A document containing the words
separately, in reverse order, or with an intervening word does not match.

## Ranking
Only exact phrase matches are ranked. The module constructs sparse document
vectors from the positional index using raw term frequency and smoothed IDF:

- TF(t,d) = number of positions recorded for term t in document d.
- IDF(t) = log10(N / DF(t)), rounded to 4 decimal places (same formula as Task 2).
- TF-IDF(t,d) = TF(t,d) × IDF(t).

The query vector uses the phrase's term frequencies with the same IDF weights.
Each matching document receives cosine similarity:

cos(q,d) = (q · d) / (||q|| × ||d||)

Results are sorted by descending similarity, then document ID for stable ties.
This keeps Task 4 consistent with Task 2's `output/tf_df_idf.json` IDF values.
The module recomputes the weights from the shared positional index using the
same base-10 logarithm and four-decimal rounding.

## Run
From the repository root, after generating the positional index:

```bash
python src/positional_index.py
python src/phrase_queries.py
```

Optional arguments:

```bash
python src/phrase_queries.py --index output/positional_index.json --output output/phrase_results.json
python src/phrase_queries.py --self-test
```

The script prints matching document IDs and their ranked cosine scores, and
writes the complete machine-readable result to `output/phrase_results.json`.

## Test coverage
Built-in tests cover consecutive matches, a gap between terms, reversed word
order, a missing term, and ranking of matching documents. Run them with
`python src/phrase_queries.py --self-test`.
